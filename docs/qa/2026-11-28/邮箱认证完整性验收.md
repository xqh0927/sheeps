# 邮箱认证功能完整性验收

2026 年 11 月 28 日。候选提交 `e26f069a`，旧客户端基线为已发布的 1.0.10（11），源码提交 `0c3a33e2`。本报告记录隔离账号的验收；用户单独授权的个人账号操作不纳入报告或测试统计。

**结论：邮箱认证主流程可用，旧版过渡、纯邮箱账号对战和全新建库仍有阻断。** 不能用“所有已有单测通过”代替这三项上线验收。

## 通过的路径

| 环境 | 本轮操作与观测 |

| Android 真机 | PHK110 使用独立测试包。新邮箱注册、邮箱验证码登录成功；账号无手机号时能进入第 1 关取牌，余牌从 12 变 11，槽从 0 变 1；排行榜能打开。在隔离模拟器用同一无手机号账号补测：主线 930 分和无尽 0 分均正常入榜并标记本人。 |
| Android 隔离模拟器 | 老手机号账号用原密码登录，个人资料提示先绑邮箱再改密。绑定、换邮箱与换手机号均成功，数据库与 UI 对应；改密和忘记密码均分别验证旧密码被拒、新密码可用；用新手机号和恢复后的密码重登，昵称、替换后的邮箱及手机号均保留。 |
| 管理后台 | Chrome 和隔离 Worker/D1 验证纯邮箱、纯手机号和双绑定三类账号的展示、搜索、重置密码、普通登录和续期；旧管理员会话及角色在数据库升级后可继续使用。44 项检查中 41 项符合预期，3 项偏差归为两处显示问题。 |

## 尚未通过的场景

| 优先级 | 场景、实际影响 | 验收标准 |
|---|---|---|
| P1 | 旧 1.0.10 提交手机号的发码、验证码登录、注册和忘记密码均收到 400。已退出且未设密码的旧用户没有自助恢复路径；直接用新邮箱登录会创建新账号。隔离样本中原账号的 88 分仍在，新账号为 0 分。 | 用正式旧请求重测四个入口。迁移后仍能找到原账号及资产；新客户端必须有高于现网 11 的版本码或其他可验证的升级路径。 |
| P1 | 纯邮箱玩家可进入对战页面，但真机两次排队均返回 400。菜单将空的手机号用作匹配玩家 ID，页面提示匹配失败。同一账号在模拟器绑定测试手机号后，与另一账号均成功进入对战房间，两端 WebSocket 均返回 101。 | 不绑定手机号，两名邮箱玩家也能用稳定的账号 ID 配对并进入同一房间。 |
| P1 | 全新 D1 按 README 先执行当前 schema，再跑增量迁移，0015 重复添加 email 列而中止；重试仍失败。上版数据库走增量升级则通过。 | 新装和从旧版升级两条部署路径均能走完，重复运行没有待处理或失败迁移。 |
| P2 | 日额度设为 2，首封发送成功。同一邮箱在冷却期点重发得到 429，又占了一个全站名额；另一用户首次发也被拒，替身实际只接单 1 封。 | 冷却内拒绝的请求不占已投递邮件额度，第二名用户可发出本应可用的第二封。 |
| P2 | 纯邮箱玩家的后台调积分、改昵称弹窗缺少对象标识。 | 在确认弹窗中能辨认操作的邮箱或账号；本次用例未写入资产。 |
| P3 | 后台排行榜按邮箱能搜到人，选中后却显示“昵称（null）”，提示也只列手机号和昵称。 | 提示及选中项使用真实可用标识。 |
| 文档与发布 | OpenAPI 四个认证示例仍传 phone，且缺少两个绑定接口；README 部署段仍列短信配置。候选隐私政策、用户协议中仍将短信和手机号描述为注册验证方式，隐私政策未列 Bird。 | 接口示例可直接使用，部署说明与对玩家展示的规则、数据用途和服务商保持一致。 |

另有一项体验差异：密码错误触发 15 分钟锁定后，即使通过邮箱成功重置密码，立刻用新密码登录仍得到 429。需要产品明确是继续等待，还是经邮箱恢复后解除锁定，并在界面说明。

## 验证边界与复查位置

- 真机、模拟器和服务端验收使用隔离数据，本地 Bird 替身的接单回执不能证明邮件到达真实收件箱。
- 对照 Bird 官方说明，当前代码使用的区域地址、Bearer 认证及发送路径匹配。验证码邮件未显式设置 `category: transactional`，官方文档注明无模板发送默认分类为营销邮件；此项为接口契约核对，没有模拟实际收件方退订行为。[Bird 发送说明](https://bird.com/docs/guides/email/sending-email)
- 主要复查位置为 `server/src/handlers/auth.ts`、`server/src/lib/email-delivery.ts`、`server/migrations/0015_email_auth.sql`、`server/src/openapi.json`、`MenuActivity.kt`、`Users.tsx` 和 `UserPicker.tsx`。未经脱敏的邮件、完整手机号、令牌和个人生产绑定结果不随报告分发。
